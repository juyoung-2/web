# Web Study Notes

이 저장소는 **웹 개발 전반을 학습하며 작성한 예제와 노트들을 정리한 프로젝트**입니다.  
HTML, CSS, JavaScript, jQuery를 이용한 프론트엔드와  
Java 기반의 웹 백엔드 기초까지 **단계적으로 학습**할 수 있도록 구성되어 있습니다.

---

## Project Structure

- **chapter01_html** : HTML 기본 구조 및 핵심 태그
- **chapter02_css** : CSS 기본 문법, 레이아웃, 스타일링
- **chapter03_javascript** : JavaScript 기본 문법 및 DOM / BOM
- **chapter04_jQuery** : jQuery 활용 및 Ajax
- **chapter05_java** : Java 기초 및 웹 백엔드 기초 개념

---

## Learning Goals

- HTML, CSS, JavaScript를 활용한 웹 페이지 구성 능력 향상
- JavaScript와 jQuery를 이용한 동적 웹 처리 이해
- Java 기반 웹 백엔드 학습을 위한 기초 역량 확보
- 웹 애플리케이션의 전체 흐름 이해 (Frontend → Backend)
